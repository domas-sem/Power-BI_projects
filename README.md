# Power BI Projects Portfolio

A growing portfolio of Power BI dashboard projects that combine data cleaning, transformation, and interactive reporting to solve practical business analysis problems.

## About This Repository

This repository is used to organize and showcase small-to-medium Power BI portfolio projects.  
Each project focuses on turning raw data into structured analysis through a combination of Python, Power BI, DAX, and data visualization.

## Tools & Skills
- Power BI Desktop
- DAX
- Power Query
- Python
- Data cleaning
- Data transformation
- Dashboard design
- Business-focused analytics

## Projects

### [Insurance Fraud Analytics](./insurance-fraud-analytics)
End-to-end analytics project built around insurance claims data.  
The project includes Python-based data cleaning, fraud-focused exploration, and a two-page Power BI dashboard covering fraud indicators, customer segments, and policy-level analysis.
