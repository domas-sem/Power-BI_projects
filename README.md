# Power BI Projects Portfolio

A growing portfolio of Power BI dashboard projects that combine data cleaning, transformation, data modelling, and interactive reporting to solve practical business analysis problems.

## About This Repository

This repository is used to organize and showcase small-to-medium Power BI portfolio projects.

Each project demonstrates an end-to-end workflow: turning raw data into structured analysis through Python-based preparation, Power Query transformations, DAX measures, data modelling, and business-focused dashboard design.

## Tools & Skills

- Power BI Desktop
- DAX
- Power Query
- Python
- Data cleaning and transformation
- Data modelling and relationships
- Calendar tables and time-based analysis
- Dashboard design, slicers, conditional formatting, and report-page tooltips
- Business-focused analytics and fraud-risk segmentation

## Projects

### [Global Superstore Analysis](./Global_superstore_analysis)

End-to-end global retail analytics dashboard built with the Global Superstore dataset.

The project includes Python-based data cleaning, raw and processed datasets, a custom DAX calendar table, data modelling, reusable DAX measures, and an interactive four-page Power BI report:

- **Overview** — headline KPIs, monthly sales trend, regional sales, and category profit.
- **Sales Trends** — sales and profit trends, with Region, Segment, and Market slicers.
- **Profitability** — profitability by category and sub-category, profit margin, and profit per order.
- **Returns & Regional** — returned orders, return rate, return patterns by region, category, sub-category, and month.

The report also includes custom report-page tooltips for deeper analysis of regions, months, sub-categories, and returns.

### [Insurance Fraud Analytics](./insurance-fraud-analytics)

End-to-end insurance claims analytics project built with Python and Power BI. The project analyzes 1,000 claims to identify fraud patterns, high-risk segments, customer-policy relationships, and financial exposure.

The project includes Python-based data cleaning, a prepared analytical dataset, DAX measures, conditional formatting, interactive slicers, and report-page tooltips. The Power BI report has three main pages:

- **Insurance Claims & Fraud Analysis Dashboard** — fraud KPIs, fraud rate by incident type and policy state, high-risk vehicle-make analysis, and an age-versus-claim-amount view by fraud status.
- **Customer & Policy Overview** — customer and policy segmentation by gender, education, state, premium, deductible, tenure, and claim amount.
- **Fraud Risk Segmentation** — investigation-focused high-risk segment priority list, policy coverage limit and incident type matrix, fraud-rate risk bands, and fraud exposure by incident type.

Key portfolio findings include 1,000 total claims, 247 fraudulent claims, a 24.70% fraud rate, and approximately $14.9M in fraudulent claim exposure. The report uses a low/medium/high fraud-risk color framework and report-page tooltips to add contextual analysis without overloading the dashboard.
